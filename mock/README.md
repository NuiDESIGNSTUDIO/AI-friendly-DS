# mock/ — 常時最新のサイト全体モック

fix済み(人間の最終OKが出た)デザインだけを置く場所。エンハンスも新規デザインも、確定した瞬間にここへ反映し、「実装との差分がない、サイト全体の最新デザイン状態」を保つ。

## 配置ルール

`reference/sharewis-act`(実装環境)の `app/views/admins/<controller>/<action>` と同じ命名規則で配置する。実装側との対応関係を保ち、将来の実装移植や現状比較をしやすくするため。

```
mock/
└── admins/
    └── users/
        ├── index.html   (一覧)
        ├── show.html    (詳細)
        ├── new.html     (新規作成)
        └── edit.html    (編集)
```

実装側にまだ存在しない画面(TOBE設計で実装が追いついていない場合)は、Figmaの構成に沿って新規にパスを起こしてよい。迷ったら人間に確認する。

## 更新ルール

- **Step5で人間の最終OKが出た時点でのみ更新する。** 検討中(fix前)のファイルは `drafts/` に置き、ここには置かない。
- 更新は上書きコピー。git履歴がそのままデザインの変更履歴になる。
- AIの作業範囲は **ここまで**。`reference/sharewis-act`(実装リポジトリ)への反映・移植は人間(エンジニア)が行う。AIは実装リポジトリへの書き込み・コミットを行わない。

## Step0での参照優先順位

現行確認の際は、次の優先順で見る。

1. `mock/` — 過去にfixした最新のデザイン意図(実装より新しい場合がある)
2. `reference/sharewis-act/` — 現行の実装(mockに無い画面はこちらが正)
